# ReClaim 🔎

### Find it. Verify it. Reclaim it.

ReClaim is a privacy-focused lost and found platform designed to help people report lost items, report found items, discover possible matches, and securely verify ownership before an item is reclaimed.

## 🚨 Problem

Traditional lost and found systems often expose too much information about an item. This can make it difficult to determine whether someone claiming an item is actually its owner.

## 💡 Solution

ReClaim keeps important identifying details private. A person claiming an item must answer verification questions based on information that is not publicly displayed.

## ✨ Key Features

- Report lost items
- Report found items
- Privacy-protected item details
- Smart matching based on item information
- Ownership verification using private details
- 2/3 verification requirement
- Unique Report IDs
- Unique Claim IDs
- Claim status tracking
- Mark items as returned
- Automatically remove returned items from available listings
- Responsive and user-friendly interface

## 🔄 How It Works

1. **Report Lost** — A user reports their lost item and provides private verification details.
2. **Report Found** — A finder reports an item while keeping sensitive identifying information private.
3. **Match** — ReClaim compares available lost and found reports to identify possible matches.
4. **Verify** — The claimant answers private questions to prove ownership.
5. **Track** — A unique Claim ID allows the user to track the claim.
6. **Reclaim** — Once the item is safely handed over, the claim can be marked as returned.

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- LocalStorage

## 🔐 Privacy & Security

ReClaim does not publicly display sensitive identifying information. Private details are used only during the ownership verification process.
